# App Store 13-inch iPad screenshots

Upload the numbered PNG files in order to the App Store Connect
`iPad 13-inch Display` screenshot slot. The terminal image leads because it
shows the native wide-screen layout introduced in version 1.0.9.

Accepted landscape dimensions are `2752 x 2064` or `2732 x 2048` pixels.
The screenshots are captured from the current app build in landscape using
the deterministic fake-relay UI fixture.

1. `01-ipad-terminal.png`
2. `02-ipad-workspaces.png`
3. `03-ipad-settings.png` (optional supporting image)
