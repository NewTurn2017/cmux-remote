# cmux Remote 2.0.0

Build: 22

## What's New - English

```text
- The relay on your computer can now update itself from official GitHub releases. It restarts only when no phone is connected, and Settings has an Update Now button.
- Settings shows the app and relay versions, and the app tells you when a newer version is on the App Store.
- Open cmux markdown tabs and text files on your phone, and see cmux browser tabs as screenshots (read-only).
- New AGENTS tab: answer Claude questions, permission requests, and plan approvals from your phone, and read Claude conversations.
- Notification title and text now show in the Inbox and in banners. Clearing notifications on your computer clears them on your phone.
- In fullscreen terminals such as Claude Code, pulling past the top or bottom edge sends Page Up or Page Down.
- Large images and documents open reliably.
- The surface tab row stays visible while you type, and Korean and English text was reviewed.
```

## Included changes

Since 1.1.4 (build 21). SHAs are on branch `feat/mobile-scroll-surface-kinds`. App = iOS app, relay = Mac daemon, shared = SharedKit contract.

- Version and contract: version 2.0.0 (build 22) for the app and the relay, and the `relay.info` and `relay.update.start` contract (shared + app, c43a3258).
- Relay auto-update: a separate launchd job follows official `vX.Y.Z` tags, builds and signs the new release in a managed clone, and restarts the relay only when no phone has been connected for 2 minutes. `install-launchd.sh --no-auto-update` turns it off (relay, 4a33c4b6).
- Settings: the app and relay versions, the relay's update state, and an Update Now button (app, fad952c2). The relay reports its version and update state through `relay.info`.
- App Store notice and text review: the app checks the App Store once a day (bundle ID and country only) and shows a dot and an Open App Store button in Settings when a newer version exists; 49 strings were translated and one Korean demo string was fixed; the app ships a privacy manifest (app, b6977882).
- Surface tab row: it stays visible while the keyboard is up (app, 3495d26e).
- Fullscreen terminals: pulling past the top or bottom edge of a screen with no scrollback (the alternate screen, for example Claude Code's fullscreen view) sends Page Up / Page Down, one key per pull (app, 61e07b54). The gesture observer now attaches on a physical device (app, 415a6acb). Tabs that are not terminals show a card instead of an empty terminal (app, 61e07b54). The relay carries surface kind and active screen, and keeps screen height + 240 rows of scrollback (relay + shared, e87e459f).
- Relay reliability: no repeated full frames when only cmux's theme counter moves (32274d9f); slow (2 s or more) and dropped RPCs are logged, and `CMUX_RELAY_TRACE_RPC=1` traces every one (46fd8ee2); file work no longer stalls the WebSocket and the relay can be signed so macOS stops asking for Downloads access after each reinstall (a8a947ff).
- Markdown and text documents: contract (shared, 3ee5a59a), relay serves cmux markdown tabs and detects bare relative paths (relay, 27815f4e), the phone renders markdown tabs and text files (app, b32a6d9a). The relay reads the path from cmux; the phone sends only workspace and surface ids.
- Browser tabs: contract (shared, fb894ef6), relay captures a tab as a JPEG of at most 1600 px under 720 KiB (relay, 681e6c82), the phone shows it as a read-only screenshot refreshed about every 2 s while on screen (app, 2ad7fc65).
- Large files: relay fetch and thumbnail frames stay under 1 MiB (relay, b05a2b50); the app accepts WebSocket messages up to 4 MiB (app, aeb4fffe).
- AGENTS tab: contracts for feed replies and Claude transcripts (shared, babfc900); the relay lists pending Claude questions, permission requests, and plan approvals and sends the phone's answer to cmux (relay, 19e7e2d0); the phone shows them and answers (app, 0cf1480d); the tab is named AGENTS and shows time left and an expiry notice (app, bbe26be4).
- Claude conversations: the relay reads session transcripts inside `~/.claude/projects`, newest page first (relay, 1c9bd61f); the AGENTS tab shows them read-only (app, 02bd8086).
- Notifications: the relay fills in the title, subtitle, and body that cmux hides on the event stream, for the Inbox and for pushes (relay + shared, a0a7c42c); the Inbox and banners show the text (app, 07a465f6); clearing notifications on the Mac removes the phone's cards (app, 25d2a2bd).

### English

```markdown
## cmux Remote 2.0.0

- **Relay auto-update** — the Mac relay now follows official release tags (`vX.Y.Z`), builds and installs new versions by itself, and restarts only when no phone is connected. Settings has a version section and an [ UPDATE NOW ] button. Turn auto-update off with `./scripts/install-launchd.sh --no-auto-update`.
- Settings shows the app and relay versions, and the app tells you when a newer version is on the App Store (once a day, it sends Apple only the bundle ID and country).
- Open cmux markdown tabs and text files on your phone, and see cmux browser tabs as screenshots (read-only).
- New **AGENTS** tab: answer Claude questions, permission requests, and plan approvals, and read Claude conversations.
- Notification title and text show in the Inbox and in banners, and clearing notifications on the Mac clears them on the phone. With an `apns` block on the relay, pushes carry the title and text through Apple's push servers (see [PRIVACY.md](https://github.com/NewTurn2017/cmux-remote/blob/main/PRIVACY.md)).
- Pull past the top or bottom edge of a fullscreen terminal such as Claude Code to send Page Up / Page Down.
- The surface tab row stays visible while the keyboard is up, and the Korean and English text was reviewed.
- Relay fixes: repeated full-screen frames, file work that stalled the WebSocket, and large files that would not open.

**Updating a 1.x relay:** run `git pull` and then `./scripts/install-launchd.sh` once on your Mac. After that, updates are automatic. If you run a development branch build, install with `--no-auto-update`.
```
