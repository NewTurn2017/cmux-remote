# cmux Remote 1.1.4

Build: 21

## What's New - English

```text
- Adds an Option + Down Arrow shortcut next to Option + Up Arrow.
- In Claude Code's fullscreen view, it can jump back to the latest output. Add "alt+down": "scroll:bottom" to the Scroll context in ~/.claude/keybindings.json on your Mac.
```

## 새로운 기능 - 한국어

```text
- Option + 위쪽 방향키 옆에 Option + 아래쪽 방향키 단축키를 추가했습니다.
- Claude Code fullscreen 화면에서 최신 출력으로 바로 내려갈 수 있습니다. Mac의 ~/.claude/keybindings.json에서 Scroll 컨텍스트에 "alt+down": "scroll:bottom"을 추가하세요.
```

## Included changes

- Option + Down Arrow key in the bottom shortcut row (iPhone) and the full shortcut row (iPad landscape). It sends `alt+down` through `surface.send_key`.
- Why the Mac binding is needed: Claude Code's only default bottom jump in fullscreen is Ctrl+End, and cmux `surface.send_key` rejects any modifier on End. With the binding, Claude Code 2.1.311 jumps to the bottom on `alt+down`. Verified on 2026-10-27.
